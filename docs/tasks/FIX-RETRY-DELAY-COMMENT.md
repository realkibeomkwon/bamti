# 작업 지시서: 재시도 간격 주석을 실제 값에 맞춘다

> 작업 당시의 진단과 지시를 남긴 기록입니다. 현재 코드의 설명이 아닙니다.

주석 한 줄만 바꾸는 작업입니다. **코드는 한 글자도 바꾸지 마십시오.** 건드리는 파일은 `src/menu_bar.cpp` 하나입니다.

---

## 1. 무엇이 어긋났는가

`FIX-WORKAREA-RETRY-BUDGET.md`(커밋 `479e727`)가 넣은 `WorkAreaRetryDelayMs` 의 주석이 사실과 다릅니다. **지시서에 적어 준 코드의 오차이므로 잘못은 지시한 쪽에 있습니다.**

```cpp
// 실패가 이어질수록 간격을 늘린다. 300, 600, 1200, ... 30000 밀리초에서 멈춘다.
UINT WorkAreaRetryDelayMs(unsigned tries) {
  UINT ms = kWorkAreaRetryMinMs;
  for (unsigned i = 0; i < tries && ms < kWorkAreaRetryMaxMs / 2; ++i) {
    ms *= 2;
  }
  return ms > kWorkAreaRetryMaxMs ? kWorkAreaRetryMaxMs : ms;
}
```

반복문의 조건이 `ms < kWorkAreaRetryMaxMs / 2`, 곧 `ms < 15000` 이므로 실제로 나오는 값은 이렇습니다.

| `tries` | 0 | 1 | 2 | 3 | 4 | 5 | 6 이상 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 반환값(밀리초) | 300 | 600 | 1200 | 2400 | 4800 | 9600 | 19200 |

`9600` 은 `15000` 보다 작아 한 번 더 두 배가 되고, `19200` 은 크므로 거기에서 멈춥니다. **`kWorkAreaRetryMaxMs`(30000)에는 끝내 닿지 않습니다.** 그 상수는 도달하는 상한이 아니라 상한을 정하는 기준값입니다.

## 2. 왜 코드를 고치지 않는가

**동작에 문제가 없기 때문입니다.** 상한이 19.2초여도 누적 18.9초 안에 여섯 번을 시도하므로, 원래 노린 "실패가 길어져도 로그를 넘치지 않게 하면서 계속 붙잡는다"를 만족합니다. 오히려 회복이 조금 빠릅니다.

검증까지 끝난 동작을 글자 하나 때문에 흔들 이유가 없으므로 **주석만 사실에 맞춥니다.**

## 3. 고칠 것

주석 한 줄을 다음 두 줄로 바꾸십시오.

```cpp
// 실패가 이어질수록 간격을 늘린다. 300, 600, 1200, ... 19200 밀리초에서 멈춘다.
// kWorkAreaRetryMaxMs 는 도달하는 상한이 아니라 두 배로 키우기를 멈출 기준이다.
```

**함수 본문은 그대로 두십시오.** 반복문의 조건도, 반환문도, `kWorkAreaRetryMinMs` 와 `kWorkAreaRetryMaxMs` 의 값도 바꾸지 않습니다.

## 4. 검증

1. `git diff` 가 주석 줄만 보여야 합니다. 코드 줄이 하나라도 바뀌었으면 되돌리십시오.
2. Release 클린 빌드가 경고 없이 통과해야 합니다. **CMake 로 빌드하십시오.** `bamti.vcxproj` 는 소스 열네 개가 빠져 있어 msbuild 로는 링크되지 않습니다.

```
cmake -S D:\repos\bamti -B <빌드 디렉터리>
cmake --build <빌드 디렉터리> --config Release
```

3. **실행 중인 `bamti.exe` 를 종료하지 마십시오.** 주석만 바뀌었으므로 지금 도는 인스턴스를 다시 띄울 이유가 없습니다. 빌드가 `LNK1104` 로 막히면 링크까지 가지 않아도 되니, 컴파일이 통과하는 것만 확인하고 그 사실을 보고하십시오.

## 5. 하지 말 것

- `kWorkAreaRetryMinMs` 나 `kWorkAreaRetryMaxMs` 의 값을 바꾸지 마십시오. 특히 `kWorkAreaRetryMaxMs` 를 19200 으로 바꾸면 반복문의 기준이 9600 이 되어 **상한이 절반으로 줄어듭니다.** 이름과 값을 맞추려다 동작을 바꾸는 함정입니다.
- 반복문의 조건을 `ms < kWorkAreaRetryMaxMs` 로 바꾸지 마십시오. 주석에 맞춰 동작을 고치는 것은 이번 지시가 아닙니다.
- 다른 주석이나 로그 문구를 함께 손대지 마십시오.
- `src/menu_bar.cpp` 외의 파일을 건드리지 마십시오.
- 이 지시서에 적히지 않은 정리나 개선을 함께 넣지 마십시오.
