# 작업 지시서 22: 배터리 충전 표시의 번개 테두리를 검은색으로 고정한다

> 작업 당시의 진단과 지시를 남긴 기록입니다. 현재 코드의 설명이 아닙니다.

가장 작은 수정이지만, 색을 정하는 근거를 남겨 두어야 나중에 테마 색을 다시 손댈 때 되돌아가지 않습니다.

---

## 1. 원인

`src/clock_renderer.cpp`의 `DrawBattery`(156행)는 충전 중일 때 번개 모양을 그립니다. 200~222행이 그 블록입니다.

```cpp
  if (charging) {
    ...
      AddRoundedPolygon(sink.Get(), pts, 6, s * 0.50f);
      sink->Close();
      brush->SetColor(D2D1::ColorF(0xFFD400));
      rt->FillGeometry(bolt.Get(), brush);
      brush->SetColor(outline);                     // <- 여기가 문제입니다
      rt->DrawGeometry(bolt.Get(), brush, stroke);
```

`outline`은 163행에서 `ClockTextColor(dark)`로 정해집니다.

```cpp
  const D2D1_COLOR_F outline = ClockTextColor(dark);
```

`src/theme.cpp`의 `ClockTextColor`는 다크 테마에서 흰색(알파 0.92), 라이트 테마에서 거의 검은색(0.10, 0.10, 0.10)을 돌려줍니다. 그래서 다크 테마에서는 노란 번개 둘레에 흰 테두리가 그려집니다.

번개의 **채움색은 `0xFFD400`으로 테마와 무관하게 고정**되어 있는데 테두리만 테마를 따라가므로, 두 색의 관계가 테마에 따라 달라집니다. 밝은 노랑 위의 흰 테두리는 경계를 흐리게 만들어 형태가 뭉개져 보입니다.

배터리 본체의 윤곽선과 눈금은 상단바 글자와 같은 색이어야 하므로 그대로 두어야 합니다. 테마를 따르지 말아야 하는 것은 **번개 테두리 하나뿐**입니다.

---

## 2. 수정 내용

`src/clock_renderer.cpp`의 217~220행을 다음으로 바꿉니다.

```cpp
      brush->SetColor(D2D1::ColorF(0xFFD400));
      rt->FillGeometry(bolt.Get(), brush);
      // 번개의 채움색은 테마와 무관하게 밝은 노랑으로 고정되어 있다. 테두리만 테마를
      // 따라가면 다크 테마에서 흰 테두리가 노란 면과 붙어 형태가 뭉개지므로, 테두리도
      // 채움색과 짝을 이루도록 검은색으로 고정한다.
      brush->SetColor(D2D1::ColorF(D2D1::ColorF::Black));
      rt->DrawGeometry(bolt.Get(), brush, stroke);
```

이 블록 아래로는 `outline`을 다시 쓰는 코드가 없으므로, 브러시 색을 되돌릴 필요는 없습니다. `outline` 지역 변수 자체는 배터리 본체와 꼭지가 계속 쓰고 있으니 그대로 두십시오.

`DrawBattery`는 `DrawBatteryIcon`(265행)으로도 노출되어 있으므로, 이 한 곳을 고치면 상단바와 앞으로의 호출처가 모두 같은 색을 씁니다. 별도로 손댈 곳은 없습니다.

---

## 3. 검증

1. Release로 빌드하고 앱을 다시 띄웁니다.
2. 충전기를 연결해 상단바의 배터리 아이콘에 번개가 나타나게 합니다.
3. **다크 테마**에서 번개 테두리가 검은색인지 확인합니다. 노란 면과 테두리의 경계가 또렷해야 합니다.
4. 설정에서 테마를 라이트로 바꾸고 같은 항목을 확인합니다. 라이트 테마에서는 원래도 거의 검은색이었으므로 눈에 띄는 변화가 없어야 정상입니다.
5. 충전기를 뽑아 번개가 사라진 상태에서 배터리 본체 윤곽선이 **테마 색을 그대로 따라가는지** 확인합니다. 다크 테마에서 흰색, 라이트 테마에서 검은색이어야 합니다. 이 항목이 어긋나면 `outline`을 잘못 건드린 것입니다.

---

## 4. 주의 사항

- 배터리 잔량 채움색(`BatteryFillColor`)과 본체 윤곽선은 이번 범위가 아닙니다. 건드리지 마십시오.
- `ClockTextColor`를 고치면 시계와 다른 위젯의 글자색까지 함께 바뀝니다. 절대 그쪽을 수정하지 마십시오.
- 알파를 넣지 말고 완전 불투명한 검은색으로 두십시오. 노란 면 위에 반투명 검정을 얹으면 어두운 노랑으로 섞여서 테두리로 읽히지 않습니다.
